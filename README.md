# Свадебное приглашение (React + Vite)

## Запуск локально
    npm install
    npm run dev

## Что менять
Всё в `src/config.js`: имена, время, ссылка на карту, Telegram, расписание, палитра, фото.
Свои фото положите в `public/photos/` и впишите `src: photo("1.jpg")`.

## Публикация на GitHub Pages (бесплатно)
1. Создайте репозиторий на github.com и загрузите туда содержимое папки.
2. Settings → Pages → Source: **GitHub Actions**.
3. После пуша в ветку `main` сайт появится на `https://ВАШ_НИК.github.io/ИМЯ_РЕПО/`.

## Ручная сборка для любого другого хостинга
    npm run build
Содержимое папки `dist/` загрузите куда угодно (сборка работает в любой подпапке).
Шрифты вшиты в сборку, внешних запросов (Google Fonts, CDN) нет.
